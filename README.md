# Bailabu – bailabu.com

Landing page for the Bailabu kids channels (EN · ES · DE · PT-BR · AR) and the Turkish sister channel Tontiş Ada.
One static `index.html` (semantic HTML5, vanilla JS) + compiled Tailwind `assets/site.css`, hosted on GitHub Pages. **After every change to `index.html`: `bash tools/build_page.sh`** (Tailwind build + static English lists for crawlers; needs node + Edge). Third-party requests: only the visitor count to GoatCounter (once `STATS_SITE` is set) and the contact form to Web3Forms when sent.

## What's on the page
- **Language**: saved choice → browser language (`navigator.languages`) → English. All public links are plain `https://bailabu.com`. `?lang=xx` remains for search engines (hreflang, sitemap) and already published links: it wins over the rest, is saved as the choice and is removed from the address bar. Arabic switches to RTL (font Baloo Bhaijaan 2, Eastern Arabic digits).
- **Friends**: tap a character → wiggle, sound and spoken name.
- **Videos** (`videoChannel`): one grid for all formats with filter tabs All · Songs · Lullabies · Quiz & games · Picture books · Stories (`CATS`, deep links `#songs` `#lullabies` `#quiz` `#books` `#tales`). A card opens the video on the visitor's own language channel if it is online there, **otherwise the English version** (user decision 2026-10-28), otherwise the Turkish original; a TR/EN chip shows when the video is in another language. Online videos come first, the rest show "Coming soon".
- **Games & riddles** (spoken with ElevenLabs since 2026-11-01: every question, praise and counted number in all six languages, `assets/voice/<lang>/<key>.mp3`. Nothing plays before the first tap; the speaker button next to the question repeats it, the note button mutes): Memory (3/6 pairs), Odd one out, Whose shadow?, How many?, Where is …? (find the friend by name), Colors, Bubbles (pop, no way to fail), Music (6 pads, WebAudio pentatonic, "Copy me!" echo mode growing from 2 to 5 notes), What comes next? (AB → AAB/ABB → ABC patterns)
- **Stories**: links to the Stories and Picture books tabs, and the picture book reader "Memo & Tonton: The Strawberry Cake" (no read-aloud: browser voices removed 2026-10-28), swipe/arrow keys and a counting page.
- **Coloring pages**: 35 pages (`assets/print/`): tap a page → big preview with a download button. Names and the downloaded A4 PDF (title, footer, QR to that language's channel; Turkish: Tontiş Ada) follow the visitor's language. The drawing itself has no text, so all languages share one preview.
- **Privacy** link in the footer (legal dialog, text `privacy` in every language). The imprint appears as soon as `IMPRINT` in `index.html` is filled in (still empty: needs the operator's name and address).
- **Contact** button in the top menu (desktop nav + mobile menu) and in the footer (next to Privacy), all `.contact-open`: form dialog (name, email, message) sent through Web3Forms (`fetch` to api.web3forms.com) to the channel mailbox; the address is never in the page, only the public access key `CONTACT_KEY` in `index.html`. While `CONTACT_KEY` is empty the button stays hidden. Honeypot `botcheck` against spam; the privacy text covers the form.
- **Visitor totals** (`count()` in `index.html`, GoatCounter, site code in `STATS_SITE`; empty = nothing is sent): aggregate numbers only, no cookies, no script from GoatCounter, nothing stored on the device. Runs only on bailabu.com and stops for Do Not Track / Global Privacy Control. Reads as paths `/tr`, `/en` … (visits per language, with the referring site) and events: `video-<id>-<lang>`, `game-<id>`, `print-<id>`, `story-open`, `youtube-<lang>`, `subscribe-<lang>`, `lang-<lang>`. Add `data-count="name"` to a link to count it. Keep "individual pageviews" off in the GoatCounter settings; if what is collected changes, update the `privacy` text in every language.
- No cookies, no ads. `localStorage` only keeps language, sound on/off, stars and memory size. Fonts are self-hosted.

## Editing
- Texts: `T` object in `index.html` (one block per language). Characters: `CAST`, videos of all formats: `VIDEOS`, channels: `CHANNELS`.
- **When a channel launches**: set `live: true` for it in `CHANNELS`.
- **When a video goes public**: add the channel code to the entry's `live` list in `VIDEOS` and its video ID to `yt` (e.g. `yt: { tr: "5nh1MCtzWP8" }`; without an ID the card opens a search on the channel) (new video: add an entry with `cat` + `tag` + a `song` line in `tools/build_assets.sh` for its card image; thumbnails with text get a `-tr` variant + `trArt: true`). Rule in `CLAUDE.md` → "Website sync".
- New story: add images to `assets/story/` and the page texts to `story` in every language.
- Coloring pages: list `PRINTS` in `index.html` (id + names per language, from `_shared\printables\character_catalog.json`); files come from `_shared\printables\` (built by `_pipeline\build_coloring_book_v2.py`). New page: rebuild the printables, add an entry to `PRINTS`, run `build_assets.sh`. Only the PDFs changed: `python tools/build_prints.py`. The app leaves the PDFs out and opens them from the website (`bailabu-app\tools\sync_web.js`).
- Game voices: `python tools/build_voices.py` makes only new or changed lines (`--dry` shows the cost). Lines come from `index.html` through `tools/voice_lines.js`, voices are set per language in `VOICES` (TR Deniz, all others Teacher Ella for now). Rerun it after changing a game text or a character name, then update `COST.md`.
- Assets are built from the YouTube project folders: `bash tools/build_assets.sh` (needs ffmpeg + uv).
