# Bailabu – bailabu.com

Landing page for the Bailabu kids channels (EN · ES · DE · PT-BR · AR) and the Turkish sister channel Tontiş Ada.
One static `index.html` (semantic HTML5, vanilla JS) + compiled Tailwind `assets/site.css`, hosted on GitHub Pages. **After every change to `index.html`: `bash tools/build_page.sh`** (Tailwind build + static English lists for crawlers; needs node + Edge). Third-party requests: only the visitor count to GoatCounter (once `STATS_SITE` is set) and the contact form to Web3Forms when sent.

## What's on the page
- **Language**: saved choice → browser language (`navigator.languages`) → English. All public links are plain `https://bailabu.com`. `?lang=xx` remains for search engines (hreflang, sitemap) and already published links: it wins over the rest, is saved as the choice and is removed from the address bar. Arabic switches to RTL (font Baloo Bhaijaan 2, Eastern Arabic digits).
- **Friends**: tap a character → wiggle, sound and a spoken "Hi! I'm …!" (`hi_<id>`).
- **Voice prompts (user 2026-11-27)**: only after a tap (browsers block earlier audio), all through `say()`: the first tap on an empty spot of the homepage greets (`v_hello`), the activity tiles say their name (`data-say` → `nav_*`), a link to `#play` says "Pick a game!" (`v_pick`), opening a game says its name (`g_<id>`) and then its task. The header speaker (`#soundTop`, all `[data-sound-toggle]`) mutes everything.
- **Videos** (`videoChannel`): one swipe row per format in `ROWS` order: Stories (opens with the picture book reader) · Quiz · Picture books · Songs · Lullabies, only live videos, rows without any are left out (deep links `#stories`/`#tales` `#quiz` `#books` `#songs` `#lullabies` are the row ids). A card opens the video on the visitor's own language channel if it is online there, **otherwise the English version** (user decision 2026-10-28). Only the Turkish page shows Turkish videos (user decision 2026-11-02): on every other page a video online only in Turkish counts as "Coming soon", and every card without its own language version carries the English title and art. An EN chip shows when the video is in another language. Videos not yet online stay in `VIDEOS` and are not shown.
- **Games & riddles** live on their own Games page (user 2026-11-27, like cocomelon.com/games): `#play` hides the homepage and shows a banner + one big card per game (`renderGameCards`, `GAMES`); a card opens `#play-<id>` (player with the tab strip and an "All games" button; switching tabs updates the address). The homepage only has a teaser (`#games`, first 6 cards + "All games"). The router `gamesRoute` registers after the deferred coloring script, whose own router also toggles `#homepage`. Game rules: visual-first rounds without written task banners; picture references for Where is?, Shadows and Colors, countable objects and sequences for Counting and What's next?. Memory (3/6 pairs with card previews), Odd one out, Bubbles and Music begin with direct play. Optional local instruction audio in all six languages (`assets/voice/<lang>/<key>.mp3`) plays only through the speaker; the note button mutes all game sound. Music keeps six WebAudio pentatonic pads and the optional 2–5-note echo game. No cumulative score. See [game maintenance and validation](docs/games.md).
- **Stories**: links to the Stories and Picture books tabs, and the picture book reader "Memo & Tonton: The Strawberry Cake" (no read-aloud: browser voices removed 2026-10-28), swipe/arrow keys and a counting page.
- **Coloring pages**: 35 pages (`assets/print/`): tap a page → big preview with a download button. Names and the downloaded A4 PDF (title, footer, QR to that language's channel; Turkish: Tontiş Ada) follow the visitor's language. The drawing itself has no text, so all languages share one preview.
- **Privacy** link in the footer (legal dialog, text `privacy` in every language). The imprint appears as soon as `IMPRINT` in `index.html` is filled in (still empty: needs the operator's name and address).
- **Contact** button in the top menu (desktop nav + mobile menu) and in the footer (next to Privacy), all `.contact-open`: form dialog (name, email, message) sent through Web3Forms (`fetch` to api.web3forms.com) to the channel mailbox; the address is never in the page, only the public access key `CONTACT_KEY` in `index.html`. While `CONTACT_KEY` is empty the button stays hidden. Honeypot `botcheck` against spam; the privacy text covers the form.
- **Visitor totals** (`count()` in `index.html`, GoatCounter, site code in `STATS_SITE`; empty = nothing is sent): aggregate numbers only, no cookies, no script from GoatCounter, nothing stored on the device. Runs only on bailabu.com and stops for Do Not Track / Global Privacy Control. Reads as paths `/tr`, `/en` … (visits per language, with the referring site) and events: `video-<id>-<lang>`, `game-<id>`, `print-<id>`, `story-open`, `youtube-<lang>`, `subscribe-<lang>`, `lang-<lang>`. Add `data-count="name"` to a link to count it. Keep "individual pageviews" off in the GoatCounter settings; if what is collected changes, update the `privacy` text in every language.
- No cookies, no ads. `localStorage` only keeps language, sound on/off and memory size; old star values are unused. Fonts are self-hosted.

## Editing
- Look (refresh 2026-11-27, ideas from big kids' sites): colour-coded icon pills in the header (+ a quiet "For parents" pill from 1280 px), chunky 3D activity tiles pulled up into the hero, a second hero button to the videos, confetti `.sprinkles` on the sections, a wavy `h2.squiggle` underline per section colour, the Color online / Print buttons inside the coloring section, a wave above the footer. Styles sit in the `<style>` block of `index.html`.
- Homepage (rebuilt 2026-11-27, user: "Cocomelon scrolls better with its tiles"): hero + four activity tiles, then horizontal swipe rows (`.shelf` / `.shelf-row`, scroll-snap, the next tile peeks in; arrow buttons only on mouse devices, `shelves()`): friends, all nine games, the video rows, coloring ("Color online" tile + all 35 printables). Channels and For parents stay below. `prerender.py` writes the rows for crawlers; `#videoShelves` ends at the comment `<!--/videoShelves-->`.
- Online coloring: `#color-online` opens a thumbnail studio with 50 pictures plus a full-workspace Blank page, including all 35 existing printables and 15 original SVG motifs. Twenty pictures support tap-to-fill Color; all 51 choices support Draw with brush, crayon, eraser, three sizes, 18 colors, independent undo/redo and local PNG export. The site is aimed at children aged 1–6 (stories, games and picture books first, songs last; changed 2026-11-13). The header's Coloring links enter it; `#coloring` remains the printable collection. See [online coloring maintenance](docs/online-coloring.md) and the [complete artwork inventory](docs/coloring-inventory.md).
- Texts: `T` object in `index.html` (one block per language). Characters: `CAST`, videos of all formats: `VIDEOS`, channels: `CHANNELS`.
- **When a channel launches**: set `live: true` for it in `CHANNELS`.
- **What is online**: ProjektHub's `data/youtube_cache.json` (its read of the public channel pages) is the reference, not `VIDEOS`. `tools/check_videos.js` compares the two in every `build_page.sh` run and lists every main video missing from the site. It only warns and it does not refresh the read: press **Check online now** in ProjektHub first. Shorts are not listed on the site.
- **When a video goes public**: add the channel code to the entry's `live` list in `VIDEOS` and its video ID to `yt` (e.g. `yt: { tr: "5nh1MCtzWP8" }`; without an ID the card opens a search on the channel) (new video: add an entry with `cat` + `tag` + a `song` line in `tools/build_assets.sh` for its card image; thumbnails with text get a `-tr` variant + `trArt: true`). Rule in `CLAUDE.md` → "Website sync".
- New story: add images to `assets/story/` and the page texts to `story` in every language.
- Coloring pages: list `PRINTS` in `index.html` (id + names per language, from `_shared\printables\character_catalog.json`); files come from `_shared\printables\` (built by `_pipeline\build_coloring_book_v2.py`). New page: rebuild the printables, add an entry to `PRINTS`, run `build_assets.sh`. Only the PDFs changed: `python tools/build_prints.py`. The app leaves the PDFs out and opens them from the website (`bailabu-app\tools\sync_web.js`).
- Game voices: `python tools/build_voices.py` makes only new or changed lines (`--dry` shows the cost). Lines come from `index.html` through `tools/voice_lines.js`, voices are set per language in `VOICES` (TR Deniz, DE Lucy Fennek since 2026-11-27, the others "Ella" = Tilly the Storyteller for now; library voices work by id, the API key cannot add voices). `SPOKEN` holds spellings for takes that came out wrong. Check new takes with Whisper (`_pipeline/fwhisper.py`). Rerun it after changing a game text or a character name, then update `COST.md`.
- Assets are built from the YouTube project folders: `bash tools/build_assets.sh` (needs ffmpeg + uv).
