# Coloring artwork inventory

Reviewed November 2026 before adding new motifs. The repository contains **35 distinct existing coloring pictures**, each represented by `assets/print/bailabu-coloring-{source}.png`, `assets/print/{source}.webp`, and six localized PDFs (**210 PDFs total**). All were visually reviewed in a contact sheet. No existing coloring SVG collection was found. Character display cards, song art, story illustrations and voice/game assets are not coloring/printable artwork.

Provenance follows the existing README pipeline: `_shared/printables/`, generated by `_pipeline/build_coloring_book_v2.py`, copied/built by the repository's tools. These are existing Bailabu assets; no third-party ownership or new license is inferred. Original PNGs, previews, PDFs and the three approved interactive definitions remain unchanged.

Totals: **3 interactive-ready**, **2 converted to Color + Draw**, **30 Draw-only**, **0 excluded as unsuitable**. Every existing picture is available for free drawing over the original linework. Raster boundaries alone are not treated as semantic region permission; detailed pictures need individually authored and reviewed region maps before enabling Color.

The two fruit conversions use the same offline threshold/contour method as the original three. Their colored contact-sheet review confirms large fruit bodies and correctly separated leaf/stem areas under preserved ink. Small parts are higher-complexity choices; large original SVG motifs provide easier targets.

The **15 newly authored motifs** are birthday cake, balloons, cupcake, rainbow, ice cream, flower, butterfly, house, little car, kite, teddy bear, smiling sun, moon and stars, dinosaur and rocket. They are original repository-owned vector content authored directly for this change, with semantic region IDs. No external asset or image generation service was used. Sources: `assets/coloring/svg/`; provenance is also recorded in each compiled JSON definition.

Final library: **50 pictures + Blank = 51 Draw choices**, **20 Color choices**, **18 curated colors**. Blank is Draw-only. Existing localized PDFs remain the paper-print route; new SVG motifs and Blank expose Save picture without an unsupported Print action.
